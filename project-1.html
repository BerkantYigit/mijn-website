Rekenmachine

C# Console Applicatie

Over dit project

Voor dit project heb ik een rekenmachine gemaakt in C# via Visual Studio. Het is een console-applicatie waarbij de gebruiker twee getallen kan invoeren en een bewerking kan kiezen. De rekenmachine heeft ook een nette opmaak met kleuren in de console.

Functies

  • Optellen
  • Aftrekken
  • Vermenigvuldigen
  • Delen
  • Foutafhandeling bij ongeldige invoer
  • Bescherming tegen delen door 0
  • Opnieuw berekenen zonder herstarten

Wat heb ik geleerd?

Tijdens dit project leerde ik werken met C# en de basisprincipes van programmeren zoals:

  • while — herhaling zolang de gebruiker wil doorgaan
  • switch — keuze maken op basis van de bewerking
  • double.TryParse — veilig omzetten van tekst naar een getal
  • Console.ForegroundColor — kleuren in de console
  • Werken met methodes zoals FoutMelding()
