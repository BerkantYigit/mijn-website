Webtechnologie intro

Over dit project

Voor dit project heb ik van nul een volledige portfolio website gebouwd. De website bestaat uit meerdere pagina's en is volledig zelf ontworpen en geprogrammeerd. Het doel was om mijn projecten, vaardigheden en ervaringen overzichtelijk te presenteren.

Pagina's

  • Home — welkomstpagina met een korte introductie en overzicht van projecten
  • Portfolio — overzicht van alle projecten met kaarten en een "Lees meer" knop
  • Contact — contactformulier met een Leaflet kaart van station Berchem
  • Projectpagina's — aparte detailpagina per project

Gebruikte technologieën

  • HTML5 — semantische opmaak met correcte heading hiërarchie
  • CSS3 — eigen stijlen met CSS variabelen en animaties
  • Bootstrap 5 — responsive layout met grid systeem
  • JavaScript — interactieve Leaflet kaart
  • Leaflet.js — interactieve kaart op de contactpagina

Wat heb ik geleerd?

Dit project leerde mij hoe je een volledige website bouwt van begin tot einde. Ik leerde werken met semantische HTML, responsive design via Bootstrap, eigen CSS schrijven met variabelen en een interactieve kaart integreren via Leaflet.js.
