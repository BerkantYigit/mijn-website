GalaxyFarFarAway

Linux oefening

Over dit project

Voor dit project kregen we de opdracht om via de Linux terminal een volledige mappenstructuur aan te maken gebaseerd op het Star Wars universum. Het project heet GalaxyFarFarAway en bevat planeten, personages en voertuigen als mappen en submappen.

Wat heb ik geleerd?

Tijdens deze oefening leerde ik werken met de Linux terminal en de volgende commando's:

  • mkdir — mappen aanmaken
  • cd — navigeren tussen mappen
  • ls — inhoud van een map tonen
  • tree — de mappenstructuur visueel weergeven
  • touch — bestanden aanmaken
